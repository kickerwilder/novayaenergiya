# Каталог электростанций — статический сайт

Всё готово к публикации: `index.html`, папки `img/` и `fonts/`. Сборщик и сервер не нужны.

## Как опубликовать на GitHub Pages
1. Создайте репозиторий и загрузите в корень содержимое этой папки (index.html, img, fonts).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://ваш-логин.github.io/название-репозитория/`.

## Как поменять цену
Откройте `index.html`, найдите блок `const PRICES`. Цена задаётся для каждой версии корпуса отдельно:

    "Z1600-4200-D": 129900,   // тёмный корпус
    "Z1600-4200-L": 134900,   // светлый корпус на колёсах

`0` — на сайте показывается «Цена по запросу». Валюта, подпись и ссылка кнопки связи — в блоке `SETTINGS`
(например, `contactHref: "https://t.me/ваш_ник"` или `"tel:+79990000000"`; пусто — кнопка скрыта).

## Коды моделей
`Z1600-4200-D` = мощность 1600 Вт, ёмкость 4200 Вт·ч, версия: `D` — тёмный корпус, `L` — светлый на колёсах.
