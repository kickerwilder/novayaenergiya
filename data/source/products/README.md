# Товары новых типов

Файл на тип: `data/source/products/<ключ типа>.json`, формат `{"products": [ ... ]}`. Типов и товаров пока нет (реестр `../product_types.json` пуст).

Поля товара: `article` (обязательно, уникальный), `name` (название, утверждает владелец), `slug` (необязательно; по умолчанию из артикула; задаётся один раз и не меняется),
`status` (`active`, `discontinued`, `draft`), `naming_approved` (`false`, пока название и классификация не проверены: товар не генерируется и не попадает в sitemap),
`fields` (значения полей типа), `price_rub` (целое, необязательно), `summary` (одно предложение), `images` (`[{"src":"img/...","width":N,"height":N,"alt":"..."}]`),
`compatible_with` (коды станций `Z1600-5000-L` или `Z1600-5000`), `replaced_by` (артикулы активных товаров), `faq` (`[{"q":"...","a":"..."}]`).
Подробно: `.claude/skills/novayaenergiya-site/SKILL.md`, раздел «Как добавить новый тип или товар».
